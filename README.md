**Mini Project Idea:**
 Our mini-project idea is to create a unit converter that will allow users to choose a field of measurements, followed by choosing the starting unit and destination unit, and lastly the value of the starting unit that will be converted. We want this unit converter to cover the bases of distance measurements, mass/weight, liquid-volume, and temperature. For many of the fields of measurements, we want to be able to do conversions between Imperial-Imperial, Imperial-Metric, and Metric-Metric. This allows for quick and easy conversions that would not require the user to convert between measurement systems. 

**Stretch Goals:**
	Our stretch goals would be including other, less common units of measurement for distance, liquid-volume, and mass/weight. While the program is expected to convert the common measurements, we want to also try including the less-used units for scientific conversions. That way, the unit converter will have more uses in both daily life and scientific calculations.
